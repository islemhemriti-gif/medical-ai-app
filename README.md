# medical-ai-app
# 🧬 Medical AI Diagnostic System

An AI-powered web application that predicts diabetes risk using machine learning and provides clinical-level explanations and visual analytics.

---

## Features

- 🧪 Diabetes risk prediction using ML model (Random Forest / Logistic Regression)
- 📊 Interactive medical data visualization
- 🧠 Clinical-style explanation of results
- 📄 Automatic PDF report generation
- 🖼️ Image upload (experimental dermatology module)
- 📈 Correlation heatmap of medical features

---

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas / NumPy
- Matplotlib / Seaborn
- ReportLab (PDF generation)

---

## How it works

1. User inputs medical parameters
2. Data is scaled using StandardScaler
3. ML model predicts diabetes risk
4. System returns:
   - Risk probability
   - Clinical interpretation
   - Downloadable report

---

## Model

- Dataset: Pima Indians Diabetes Dataset
- Algorithm: Random Forest Classifier
- Features:
  - Glucose
  - BMI
  - Age
  - Blood Pressure
  - Insulin
  - Skin Thickness
